# A Little Somewhere

A personal digital scrapbook for journaling, planning, reflection, and keeping everyday memories.

## About the Project

**A Little Somewhere** is a personal web application I created to bring different parts of my daily life into one space—from writing journal entries and organizing tasks to saving photos and planning solo dates.

I wanted it to feel like a personal notebook: soft, comfortable, and enjoyable to return to. Its pink palette, handwritten accents, hearts, bows, and scrapbook details reflect that idea.

## Why I Built It

This project combines my interest in web development with the idea of making time for myself and appreciating ordinary moments.

It also gives me a practical way to learn how to build an application with several connected features. Beyond its appearance, I am working on making interactions clearer, saving more reliable, and the experience comfortable on both desktop and mobile.

## Features

- **Journal** — Write daily entries, select moods, format text, and attach notes to highlights.
- **Planner** — Organize daily tasks, mark priorities, track completion, and create recurring to-dos.
- **Reflect** — Answer daily prompts, record gratitude, and make time for personal check-ins.
- **Spin** — Discover randomized solo-date activities and small side quests.
- **Solo Date Passport** — Record experiences through notes, ratings, photos, and personal to-dos.
- **Memories** — Keep multiple photos and a shared caption for each date within the Journal.

## Technology

The project uses **HTML, CSS, and TypeScript**, with **Vite** for development and production builds. **Node.js and npm** support the development tools and dependencies.

The application also includes a web app manifest and service-worker functionality as part of its progressive web app foundation.

## What I’m Learning

Through this project, I am practicing:

- Organizing application code into reusable modules.
- Managing application state and browser storage.
- Handling autosave, image uploads, and asynchronous operations.
- Creating responsive layouts and accessible controls.
- Testing features and fixing bugs.
- Using Git and GitHub to manage development.

## Project Status

**A Little Somewhere is an ongoing personal project.** I am continuing to improve its functionality, privacy controls, responsiveness, and visual consistency as I learn.

The goal is to create a useful everyday application that feels personal while helping me grow as a developer.
